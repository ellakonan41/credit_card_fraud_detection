Pourquoi le seuil de décision est à 13,5 % et non 50 % ?

Le modèle produit une probabilité de fraude entre 0 et 100 %. Il faut choisir à partir de quel niveau on déclenche une alerte. En détection de fraude, laisser passer une fraude coûte bien plus cher que vérifier une fausse alerte. On abaisse donc ce seuil à 13,5 % : le modèle signale au moindre doute sérieux, ce qui lui fait détecter environ 88 % des fraudes. Ce seuil a été choisi en optimisant le F2-score, une métrique qui pèse le rappel (fraudes détectées) plus lourd que la précision.

Les 28 variables V1–V28 du dataset sont anonymisées par transformation PCA (confidentialité des clients et commerçants) — non affichées ici car illisibles pour un humain. Le modèle, lui, les exploite pleinement.
